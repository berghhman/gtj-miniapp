# GTJ — мини-приложение для Telegram

Магазин тюнинга и детейлинга китайских автомобилей (Geely Monjaro, Preface, Tugella, Atlas, Cityray, Li Auto и др.).
Сейчас это **визуальный прототип**: все экраны кликабельные, но цены, остатки, клиент и заказы демонстрационные, бэкенда нет.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Мини-апп целиком: разметка, стили и логика в одном файле, без сборки |
| `img/` | Фото товаров, работ и автомобилей (сжатые до ~700 px) |
| `logo/gtj-logo.svg` / `.png` | Основной логотип — седан анфас в стиле наклейки |
| `logo/gtj-avatar.svg` / `.png` | Квадратная версия 1024×1024 для аватарки бота и иконки мини-аппа |
| `logo/build_logo.py` | Скрипт, который генерирует оба SVG (геометрия описана для левой половины и зеркалится) |

## Экраны

- **Главная** — выбор своего авто, баннер пакета Stage 2, категории, хиты под выбранную модель, прошивки и детейлинг, работы из бокса.
- **Каталог** — поиск по названию и артикулу, фильтр по категории и по авто, сортировка.
- **Карточка товара** — галерея, артикул, наличие, совместимость, варианты (цвет / диаметр), опция установки в боксе, характеристики.
- **Корзина** — количество, установка по позициям, самовывоз / СДЭК / курьер, запись в бокс (день и время), промокод (`GTJ10` = −10% на детали), списание бонусов до 20%, оформление.
- **Личный кабинет** — карта GTJ Club, гараж с госномерами, ближайшая запись, заказы со статусами, избранное, уведомления, чат с менеджером.

## Запуск локально

Открыть `index.html` в браузере — ничего устанавливать не нужно.
Вне Telegram сверху рисуется имитация шапки Telegram; внутри Telegram она скрывается автоматически.

## Публикация как Telegram Mini App

1. **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
   Через минуту приложение будет доступно по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
2. **BotFather:** `/newbot` — создать бота, затем `/newapp` (или *Bot Settings → Menu Button*) и указать ссылку с GitHub Pages.
3. Аватарка бота и иконка мини-аппа — `logo/gtj-avatar.png`.

SDK Telegram (`telegram-web-app.js`) уже подключён: внутри Telegram подтягивается имя клиента, работает системная кнопка «Назад» и вибрация.

## Перегенерация логотипа

```bash
pip install fonttools cairosvg
python3 logo/build_logo.py
```

## Что дальше

- Каталог из таблицы или CRM вместо данных в `index.html` (массив `P`).
- Приём заказов: бот получает заказ через `Telegram.WebApp.sendData` или ваш API и пишет менеджеру.
- Оплата через ЮKassa / СБП, реальные слоты записи в бокс.
